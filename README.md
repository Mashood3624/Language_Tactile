# Language Tactile GitHub Pages

This repository is set up to publish a research paper website from the `gh_pages` branch.

## What is included

- `index.html`: the research-paper landing page
- `styles.css`: page styling
- `.nojekyll`: ensures GitHub Pages serves the root files correctly

## Next steps

1. Add your paper PDF and supporting assets.
2. Customize the page sections and copy.
3. Commit and push the files to the `gh_pages` branch.
4. Verify the site at `https://mashood3624.github.io/Language_Tactile/`.
